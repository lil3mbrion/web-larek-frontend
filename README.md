Модель данных(бизнес логика) 

 

Все необходимые классы для модели данных и АПИ можно найти в src/types/index.ts 

 

Class IOrderResponse 

Описывает, то в каком виде данные о заказе пользователя отправятся на сервер, в данном случае его id и total - цена заказа. 

 

class IBasketModel 

Описывает, объект корзины, которая содержит список товаров, используем Map для нумерации каждого товара в списке. Так же содержит методы для добавления нового товара или удаления какого-то из списка. 

 

class IProduct 

Описывает объект товара, а именно его id, описание, название, картинку,  категорию и цену, которая может быть нулевой. 

Class IOrder 

Описывает объект заказа, а именно способ платежа(онлайн/оффлайн), email, номер телефона, адрес, итоговую сумму и сам список id товаров. 

 

class IWebApi 

Реализует основные запросы к серверу, а именно GET запрос на получение всех товаров, GET запрос на получение конкретного товара по его id и POST запроса на создание заказа, который принимает сам объект заказа. 

 

class IAppModel 

Основной класс, описывающий полную модель данных и все возможные состояния нашего приложения. Содержит в себе поля: список всех товаров, выбранныq товар, корзину, итоговую цену все выбранных товаров, заказ, открытое модальное окно,  флаг, уведомляющий нас о правильно заполненной форме, сообщение об ошибках валидации. А так же методы: GET запрос на получение всех товаров, GET запрос на получение конкретного товара по его id, POST запрос на создание заказа, который принимает сам объект заказа, выбор товара, принимает id товара, выбрать способ оплаты, принимает выбранный способ(онлайн/оффлайн), добавить товар в корзину, принимает его id, удалить товар из корзины, так же по его id, очистить корзину, заполнить адрес и способ оплаты, принимает объект с адресом и выбранным способом, заполнить информация, принимает объект с номером и email, функция для проверки валидации, открыть модальное окно, принимает выбранное модальное окно и закрыть модальное окно. 

 

Отображение 

 

Все необходимые классы для отображений можно найти в src/types/index.ts 

 

class CardFullSettings 

Класс для вывода всей необходимой информации о товаре в полном размере, а именно поля: картинка, категория, описание, наименование, кнопка для добавления товара в корзину, цену, а  так же содержит поле fullClass с наименованием класса для полного отображения карточки(card__full), а так же дополнительно флаг isFull для понимания нужен ли сейчас этот класс. 

 

class CardCompactSettings 

Класс для вывода всей необходимой информации о товаре в корзине, а именно поля: индекс, наименование, кнопку для удаления из корзины, цену, а  так же содержит поле compactClass с наименованием класса для неполного отображения карточки в корзине(card__compact), а так же дополнительно флаг isCompact для понимания нужен ли сейчас этот класс. 

 

 

 

class CardCatalogSettings 

Класс для вывода всей необходимой информации о товаре в   галерее, а именно поля:  наименование, цену,  картинку и категорию. 

 

class BasketSettings 

Класс для отображения корзины, содержит все необходимые поля для ее корректного вида, а именно наименование модального окна корзины, контейнер куда будут добавляться все товары, список товаров, итоговая сумма и кнопка. 

 

class ModalSettings<T> 

Содержит в себе все необходимые поля для отображения любого модального окна, а именно поле контент, где мы используем джинерик тип(контент может быть любым),  кнопка для закрытия, активный класс и флаг для понимания, когда модальное окно должно быть активным, а когда нет. 

 

Class OrderSettings 

Описывает отображение формы для указания выбора платежа и адреса доставки, содержит поля: наименование модального окна заказа, первую кнопку для оплаты онлайн, вторую кнопку для оплаты при получении, наименование для строки ввода с  адресом,  само поле ввода для адреса, кнопка, поле для вывода ошибок валидации и флаг для состояния валидности всей формы. 

 

Class ContactsSettings 

Описывает  отображение формы с информацией о покупателе, номер и email, содержит поля: наименования для строки ввода с номером и email, два поля ввода, кнопку, поле для вывода ошибок валидации и флаг для валидности всей формы. 

 

class SuccessSettings 

Описывает отображение уведомления об успешной покупке, содержит в себе поля: наименование уведомления, итоговую списанную сумму и кнопку.

enum AppStateEvent 

Те блоки информации об изменении, которых  мы хотели бы уведомлять. 

 

enum AppModal 

Необходим для уведомления о том, какое модальное окно сейчас открыто или же не открыто вовсе(состояние none). 

 

type ApiListResponse<Type> 

Универсальный тип, именно в таком виде приходит ответ на GET запрос по ручке /product/ , а именно кол-во товаров  и массив объектов всех товаров.
