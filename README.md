Модель данных(бизнес логика) 


interface IOrderResponse 

Описывает, то в каком виде данные о заказе пользователя будут получены с сервера, в данном случае его id и total - цена заказа. 
 
interface IProduct 

Описывает объект товара, а именно его id, описание, название, картинку,  категорию и цену, которая может быть нулевой. 

interface IOrder 

Описывает объект заказа, а именно способ платежа(онлайн/оффлайн), email, номер телефона, адрес, итоговую сумму и сам список id товаров. 

class WebApi 

Реализует основные запросы к серверу, а именно GET запрос на получение всех товаров, GET запрос на получение конкретного товара по его id и POST запроса на создание заказа, который принимает сам объект заказа. 

class AppModel 

Основной класс, описывающий полную модель данных и все возможные состояния нашего приложения. Содержит в себе поля: список всех товаров, выбранный товар, корзину, итоговую цену всех выбранных товаров, заказ, открытое модальное окно, уведомляющий нас о правильно заполненной форме, сообщение об ошибках валидации, объект webApi, адресс, выбранный способ оплаты, номер телефона, email, флаг валидности orderForm, флаг валидности contactsValid, флаг валидности Basket. А так же методы: GET запрос на получение всех товаров, GET запрос на получение конкретного товара по его id, POST метод на создание заказа, который принимает сам объект заказа, выбор товара, принимает id товара, проверка наличия товара в корзине по его id, добавить информацию из формы в order, добавить товар в корзину, принимает его id, удалить товар из корзины, так же по его id, очистить корзину, заполнить адрес и способ оплаты, принимает объект с адресом и выбранным способом, заполнить информация, принимает объект с номером и email, функция для проверки валидации формы заказа, функция для проверки валидации формы контактной информации, назначить модальное окно, принимает выбранное модальное окно, обновить итоговую цену в корзине, метод для проверки пустоты корзины. 


Отображение 

Все необходимые типы для отображений можно найти в src/types/index.ts 

class CardFull 

Класс для вывода всей необходимой информации о товаре в полном размере, а именно поля: картинка, категория, описание, наименование, кнопка для добавления товара в корзину, цену, а  так же содержит поле id. Содержит метод для обновления состояния кнопки.

class CardCompact

Класс для вывода всей необходимой информации о товаре в корзине, а именно поля: индекс, наименование, кнопку для удаления из корзины, цену и id. 

class CardCatalog

Класс для вывода всей необходимой информации о товаре в галерее, а именно поля:  наименование, цену,  картинку, категорию, кнопка которая является оберткой для товара и id. 

class BasketView

Класс для отображения корзины, содержит все необходимые поля для ее корректного вида, а именно наименование модального окна корзины, контейнер куда будут добавляться все товары, emptyMessage(новый DOM элемент, будет появляться когда корзина пустая), итоговая сумма и кнопка. 

class Modal

Содержит в себе все необходимые поля для отображения любого модального окна, а именно поле контент,  кнопка для закрытия. А так же методы open() и close(). 

Class Order

Описывает отображение формы для указания выбора платежа и адреса доставки, содержит поля: наименование модального окна заказа, первую кнопку для оплаты онлайн, вторую кнопку для оплаты при получении, наименование для строки ввода с  адресом,  само поле ввода для адреса, кнопка, поле для вывода ошибок валидации и выбранный способ оплаты. А так же метод setActiveButton, который принимает выбранную кнопку, а именно способ оплаты, для выделения соответствующей кнопки. 

Class Contact

Описывает  отображение формы с информацией о покупателе, номер и email, содержит поля: наименования для строки ввода с номером и email, два поля ввода, кнопку, поле для вывода ошибок валидации. 

class Success

Описывает отображение уведомления об успешной покупке, содержит в себе поля: наименование уведомления, итоговую списанную сумму и кнопку. 

class Page

Описывает отображение главную страницу, содержит поля с картинкой логотипа, кнопку корзины, каталог с товарами и счетчик. Содержит методы для обновления счетчика и добавления списка карточек на страницу.
